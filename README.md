# EchoLens

EchoLens implements a real-time, event-driven system for asynchronous data processing and high-performance system management.

EchoLens is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/irenascent/EchoLens.git`
2. `cd EchoLens`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure EchoLens, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
